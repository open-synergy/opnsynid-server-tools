==================
User Group Section
==================


Groups the application groups shown on the user "Access Rights" tab into
named, orderable sections (``user_group_section``), assigned per
application via ``ir.module.category.section_id``. Applications without a
section are shown separately in an "Other Groups" tab as a plain
many2many field.


Installation
============

To install this module, you need to:

1.  Clone the branch 14.0 of the repository https://github.com/open-synergy/opnsynid-server-tools
2.  Add the path to this repository in your configuration (addons-path)
3.  Update the module list
4.  Go to menu *Apps -> Apps -> Main Apps*
5.  Search For *User Group Section*
6.  Install the module
